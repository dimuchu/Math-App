# Getting Started

Краткая инструкция по запуску, сборке и тестированию MentalMath.

## Требования

- **macOS** 15.0+ (Sequoia)
- **Xcode** 16.0+ (рекомендуется последняя стабильная версия)
- **iOS Simulator** — скачать через Xcode → Settings → Platforms → iOS 18+

## Открыть проект

```bash
cd "/Users/dmitrij/Desktop/dev/Math App"
open "Math App.xcodeproj"
```

## Сборка

### Через Xcode (рекомендуется)

1. Открой проект (`Math App.xcodeproj`)
2. Выбери схему **Math App** (верхняя панель)
3. Выбери устройство: **iPhone 16** (симулятор) или **My Mac**
4. `Cmd + B` — собрать проект
5. `Cmd + R` — запустить

### Через командную строку

Убедись, что Xcode выбран как активный developer tools:

```bash
# Проверить текущий путь
xcode-select -p

# Если показывает /Library/Developer/CommandLineTools, переключить:
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
```

Сборка:

```bash
# Для macOS (работает без iOS Simulator)
xcodebuild -project "Math App.xcodeproj" -scheme "Math App" -configuration Debug -destination 'platform=macOS' build

# Для iOS Simulator (нужен установленный iOS SDK)
xcodebuild -project "Math App.xcodeproj" -scheme "Math App" -configuration Debug -destination 'platform=iOS Simulator,name=iPhone 16' build
```

Успешная сборка заканчивается строкой `** BUILD SUCCEEDED **`.

## Запуск на симуляторе

1. В Xcode выбери **iPhone 16** (или другой симулятор) в верхней панели
2. Нажми `Cmd + R`
3. Откроется симулятор с приложением

## Что проверить (тест-план)

### 1. Онбординг (первый запуск)

- [ ] Появляются 2 страницы онбординга (свайп между ними)
- [ ] Кнопка **Skip** → переход на главный экран (скиллы = 0.5)
- [ ] Кнопка **Start Diagnostic** → начинается диагностика (12 задач)
- [ ] Диагностика: задачи от простых к сложным, все 4 операции
- [ ] После диагностики — экран результатов со скилл-барами
- [ ] **Start Training** → главный экран

### 2. Главный экран (Home)

- [ ] TabView с 3 вкладками: Home, Statistics, Settings
- [ ] Карточки **Practice** и **Time Attack**
- [ ] Нажатие на карточку → sheet с настройкой (слайдер)
- [ ] После стрика > 0 — badge с огоньком

### 3. Тренировка — Practice

- [ ] Слайдер выбора количества задач (5–50, шаг 5)
- [ ] **Start** → полноэкранный режим тренировки
- [ ] Задача отображается крупно (56pt числа)
- [ ] Нампад: цифры, delete, минус (toggle), submit
- [ ] Submit заблокирован при пустом вводе
- [ ] Правильный ответ → зелёная вспышка (0.3s) → следующая задача
- [ ] Неправильный → красная вспышка + правильный ответ (1.0s)
- [ ] Кнопка ✕ → закрытие тренировки
- [ ] После всех задач → экран результатов (accuracy, solved, errors, avg time, streak)
- [ ] **Try Again** → новая сессия, **Home** → возврат

### 4. Тренировка — Time Attack

- [ ] Слайдер выбора времени (10–300s, шаг 10)
- [ ] Таймер обратного отсчёта (формат M:SS)
- [ ] При <10s таймер краснеет
- [ ] По истечении времени → экран результатов (problems solved)

### 5. Нампад

- [ ] Все цифры 0–9 работают
- [ ] Delete удаляет последнюю цифру
- [ ] Минус переключает знак (для вычитания с отрицательным ответом)
- [ ] Ограничение: макс 7 цифр, без ведущих нулей

### 6. Статистика

- [ ] Hero-метрики: total solved, accuracy, streak
- [ ] Скилл-бары по операциям (после первой сессии)
- [ ] Список недавних сессий с датой, режимом, результатом
- [ ] При пустой истории — placeholder

### 7. Настройки

- [ ] Включение/выключение операций (минимум 1 всегда включена)
- [ ] Выбор сложности (Easy / Medium / Hard)
- [ ] Тема (System / Light / Dark) — применяется сразу
- [ ] **Retake Diagnostic** → сброс скиллов + повторный онбординг
- [ ] **Reset All Progress** → confirmation dialog → полный сброс

### 8. Edge cases

- [ ] Деление: все ответы целые (без остатка)
- [ ] Вычитание: отрицательные ответы вводятся через кнопку минуса
- [ ] Стрик: не засчитывается если < 3 задач в сессии
- [ ] Повторный запуск: онбординг не показывается

## Сброс данных

Для полного сброса (если нужно заново пройти онбординг):

- **В приложении:** Settings → Reset All Progress
- **Через симулятор:** Device → Erase All Content and Settings
- **Удалить данные приложения:** В симуляторе — удалить приложение и переустановить (`Cmd + R`)
